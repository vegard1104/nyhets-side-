## Komponentspesifikasjoner

### Profilbilde / Avatar
- **Størrelse:** 80px desktop, 64px mobil
- **Form:** Sirkulær (`rounded-full`)
- **Fallback:** Gradient med brukerens initialer
- **Kant:** `3px solid white`, `shadow-md`

### XP-kort (Hero)
- **Bakgrunn:** `linear-gradient(135deg, xp-500, brand-600)`
- **Tekst:** Hvit
- **Radius:** `16px`
- **Innhold:** Nivånavn, progressbar, streak og total XP
- **Skygge:** `shadow-lg` med lilla tint

### Heatmap
- **Implementasjon:** CSS Grid, 7 rader × ~52 kolonner
- **Cellestørrelse:** `12px` med `2px` gap
- **Fargeskala:**
  - 0 artikler: `neutral-100`
  - 1-2: `brand-100`
  - 3-5: `brand-300`
  - 6+: `brand-600`
- **Interaksjon:** Hover viser tooltip med dato og antall
- **Scroll:** Horisontal på mobil, viser siste 12 uker

### Nivå-fremgang (Level Timeline)
- **Layout:** Horisontal linje med noder
- **Fullførte noder:** Fylt sirkel i `brand-600`
- **Aktiv node:** Fylt sirkel med pulserende ring
- **Fremtidige noder:** Tom sirkel i `neutral-300`
- **Linje:** `2px` mellom noder, fylt til nåværende nivå

### Statistikk-rutenett
- **Layout:** `grid-cols-2` mobil, `grid-cols-4` desktop
- **Kort:** `neutral-50` bakgrunn, `12px` radius
- **Ikon:** 24px, semantisk farge
- **Tall:** `text-2xl font-bold`
- **Etikett:** `text-xs text-neutral-500`

### Lesehistorikk (Tidslinje)
- **Gruppering:** Etter dag (I dag, I går, dato)
- **Layout:** Vertikal liste med tidsangivelse
- **Kilde:** Pill-badge med kildenavn
- **Interaksjon:** Klikk navigerer til artikkel
- **Paginering:** "Vis mer" knapp, laster 20 om gangen
